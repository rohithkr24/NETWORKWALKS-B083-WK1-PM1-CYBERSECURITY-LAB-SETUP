# NETWORKWALKS-B083-WK1-PM1-CYBERSECURITY-LAB-SETUP
# Cybersecurity Lab Setup – Installing Kali Linux on VirtualBox

##  Project Overview

This project focuses on setting up a **virtual cybersecurity and penetration-testing laboratory** using **VirtualBox** and **Kali Linux**.

The purpose of this lab is to create a **controlled and isolated environment** where cybersecurity tools and techniques such as **network scanning, reconnaissance, vulnerability assessment, and security testing** can be explored safely and repeatedly.

The laboratory is configured using a **private virtual network**, allowing additional virtual machines to be added later as target systems for **authorized security testing and experimentation**.

---

##  Objectives

* Set up and configure **Kali Linux** as a virtual machine using Oracle VirtualBox.
* Create an **isolated virtual cybersecurity environment** for security testing.
* Understand the basic configuration of **virtual networking** in VirtualBox.
* Install and explore commonly used **cybersecurity and penetration-testing tools**.
* Build a foundation for practicing **ethical hacking, vulnerability assessment, and network security**.
* Create an environment where additional target machines can be added for future security experiments.

---

##  Purpose of the Project

* To gain **hands-on experience with Kali Linux** and its cybersecurity tools.
* To understand how a **virtual cybersecurity lab** can be designed and configured.
* To practice security concepts in a **safe, controlled, and authorized environment**.
* To experiment with **network reconnaissance and vulnerability assessment techniques** without affecting real-world systems.
* To develop practical knowledge that can support further learning in **Cybersecurity, Ethical Hacking, and Penetration Testing**.
* To provide a reusable lab environment for **future cybersecurity projects and experiments**.

---
